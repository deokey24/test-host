## 0. 한 페이지 요약

### 지금 측정 "가능"한 것 (DB에만 있음)
- 회원가입 폼의 **자기보고형 유입경로**: `signup_channel`(체크박스 8종), `search_keyword`(자유입력), `referrer_code` — `members` 테이블에 저장됨
- **결제 사실**: `payments`(approved/expired/failed, 금액, 승인시각, 쿠폰 사용), 상품(`vod_course_id`)별 매출
- 가입 → 첫 결제까지 기간, 재구매, 쿠폰 사용률, 마케팅 수신동의 비율
- 결제창 열기(pending) → 승인 전환율 (결제 버튼 클릭 이후 구간만)

### 지금 측정 "불가능"한 것 (추적 도구 0개)
- **어떤 검색어/어떤 채널(인스타·구글·네이버)에서 들어왔는지** — GA4, GTM, 네이버 애널리틱스, Meta 픽셀, 카카오 픽셀, Clarity 전부 **미설치**
- **방문자 수, 페이지 체류시간, 이탈, 어느 페이지를 보고 결제했는지** — 서버 접근 로그 외엔 전무
- 비회원 방문자 전체의 행동 (회원가입 전 단계가 완전히 블랙박스)
- 광고비 대비 성과(ROAS), 채널별 CAC
- 구글/네이버 **검색 노출·클릭 키워드** — 서치콘솔·서치어드바이저 **미등록**(인증 메타태그 없음), `robots.txt`·`sitemap.xml` **없음**

### 미리 알아둘 핵심 한계 (3-5 상세)
- 도구를 다 깔아도 **"사람 A가 '편입논술'로 검색해서 들어와 결제했다"를 사람 단위로 정확히 아는 건 검색광고 유입만** 가능. 오가닉(무료) 검색은 검색엔진이 검색어를 사이트에 넘겨주지 않아 **검색어별 노출·클릭 합계**(서치콘솔·서치어드바이저)까지만 보임.
- 분석 도구는 **전부 무료**. 돈이 드는 건 검색광고를 집행할 때의 클릭당 광고비뿐(3-6).

### 회의에서 결정해야 할 것
1. 분석 도구 세트 승인: GA4+GTM, Google Search Console, 네이버 서치어드바이저, 네이버 애널리틱스, MS Clarity (전부 무료)
2. **계정 소유권**: 원청 명의의 Google/네이버/Meta/카카오 계정으로 만들고 개발사에 편집 권한 부여 (개발사 계정으로 만들면 나중에 이관 문제)
3. **UTM 규칙**과 링크 관리 주체: 인스타 프로필·네이버 카페·블로그·카카오채널·광고 링크에 UTM을 누가 붙이는가
4. 2단계(서버측 유입경로 저장 → 매출을 채널별로 귀속) 착수 여부와 우선순위
5. 현재 운영 중인 광고·채널 현황 공유: 네이버 검색광고/파워링크, 인스타 광고, 카페 운영 현황, 유튜브 등 (개발사는 전혀 모르는 상태)
6. **검색광고 소액 테스트** 여부: 키워드별 결제율을 "사람 단위"로 알 수 있는 유일한 방법이므로, 네이버 검색광고 핵심 키워드 소수·소액 테스트 집행 의사와 예산 범위
7. 가입폼 **검색키워드 입력 방식 변경**(필수화 또는 선택지화) 수용 여부 — 광고 없이 키워드→결제를 근사하는 가장 싼 방법
8. 개인정보처리방침에 분석도구·쿠키·픽셀 기재 갱신 (원청 법무/운영 확인)

> **중요**: 모든 웹 분석 데이터는 **설치한 날부터** 쌓입니다. 과거 데이터는 소급 불가 → 회의에서 결정이 늦어지는 만큼 데이터 공백이 길어집니다. 2026년 편입 시즌(연말~1월) 전에 최소 1단계는 깔려 있어야 시즌 데이터를 확보할 수 있습니다.

### 1-4. 공통 삽입 지점
- 19개 HTML 중 17개가 `header.js`를 로드(`public-figma/index.html:77` 등). 미포함: `lecturePlayer.html`, `payupReturn.html`(둘 다 분석 불필요). → GTM 컨테이너 스니펫은 **각 HTML `<head>`에 직접** 넣는 게 정석(헤더 JS에서 늦게 주입하면 페이지뷰 누락 가능). 19개 파일 반복 작업이지만 단순.

- 사이트는 다중 HTML 페이지(SPA 아님)라 페이지뷰 추적·SEO엔 유리

## 2. 운영 DB 집계 (2026-10-11 기준, SELECT만)

### 회원
- 전체 1,881명 = 기존회원(`member_group`=1000, 2026-07-27 이전 이관) 1,773 + **신규 가입 108**(2026-07~10)
- 신규 가입 월별: 2026-07: 1 · 08: 39 · 09: 32 · 10(11일까지): 36
- 기존회원 연도별(참고용 시즌성): 2023년 413명(7~10월에 263명 집중), 2024년 305명(7~10월 163명), 2025년 322명(9월 65명 피크), 2026-02월 71명 피크 → **7~10월 + 2월에 가입이 몰리는 패턴**이 수년간 반복됨
- 마케팅 수신동의(신규 108명): 이메일·SMS 모두 허용 14명(13%), 모두 거부 89명(82%) → 리타게팅용 자사 채널(문자/이메일)은 좁음

→ 검색키워드 입력(전체 회원 누적, 레거시 포함): 독편사 35 · 편입 25 · 편입논술 24 · 연고대 편입 13 · 한예종 논술 11 · 논술 9 · 연세대 편입 6 … → **브랜드 검색("독편사") + "편입논술"·"연고대 편입" + 한예종**이 핵심 키워드 후보.

### 결제 (`payments`)
- approved **45건 / 18,048,000원** (2026-08 18건 490만 · 09 20건 1,127만 · 10월 11일까지 7건 188만)
- expired 100건(결제창 열고 이탈 또는 중복 클릭), failed 2건
- 결제 시도 회원 43명 → 결제 성사 회원 **34명(79%)**. 결제자 34명은 **전원 신규가입(1001) 그룹**
- 쿠폰 사용 23/45건(51%), 그중 0원 전액할인 2건. 쿠폰 23장 사용완료·6장 등록·5장 미등록(템플릿 2종)
- **가입 → 첫 결제**: 당일 22명(65%) · 1~3일 7 · 4~7일 1 · 8~30일 2 · 31일+ 2 → 대부분 **"살 마음으로 와서 가입하고 바로 결제"**. 즉 가입 시점의 유입경로 ≒ 결제 시점의 유입경로로 볼 수 있어, 서버측 유입경로 저장(2단계)이 매출 귀속에 효과적
- 재구매: 1회 25명 · 2회 7명 · 3회 2명
- 상품별 승인 매출: 연고대 편입논술 프리미엄반[첨삭] 5건 720만(건당 144만) · 핵심 완성 11건 339만 · 독해학개론 8건 209만 · 논술 유형별 대처법 5건 192만 · 자료해석 특강 7건 189만 · 개념지식강의 7건 86만 · 연세대 수시논술 특강 1건 60만 · 고려대 학업계획서 1건 10만
- 수강등록 `member_vod_enrollments`: 결제 경유 45건(34명) vs 관리자 수동 50건(42명) → 아직 수동 등록이 절반

### 해석 포인트 (회의용)
- 온라인 상품(DOCK PASS)은 **8월 런칭 후 3개월, 월 매출 190만~1,100만원, 결제자 34명** 규모. 마케팅 성과 측정의 기준선(baseline)이 이제 막 생기는 단계.
- 유일한 유입 데이터가 자기보고형이고 체크박스에 SNS 항목이 없어 **"인스타에서 왔다"는 사실은 현재 어디에도 기록되지 않음**.

## 3. 사용자 질문별 "어떻게 알 수 있나" 매핑

### Q1. 인스타·구글·네이버에서 **어떤 검색어**로 들어왔나?
| 수단 | 알 수 있는 것 | 한계 |
|---|---|---|
| **Google Search Console** | 구글 검색에서 노출·클릭된 **실제 검색어**, 순위, CTR, 페이지별 | 클릭 이후 결제까지는 안 이어짐(GA4와 연결하면 랜딩페이지 단위로 근사) |
| **네이버 서치어드바이저** | 네이버 검색 유입 키워드(일부), 색인 상태, 사이트 진단 | 구글보다 키워드 리포트가 빈약 |
| **네이버 애널리틱스** | 네이버 검색 유입 시 **검색어**를 일부 보여줄 수 있음(국내 필수) | 기능 단순, 전환 분석 약함. 브라우저 리퍼러 정책 변화로 실제 얼마나 보이는지는 **설치 후 확인** |
| **네이버 검색광고 / 구글 Ads 키워드 리포트** | **유료** 키워드별 클릭·비용·전환 (광고 집행 시) | 광고 계정 필요 |
| GA4 | 오가닉 검색어는 **거의 안 보임**(`(not provided)`), 소스가 google/naver라는 것만 | 검색어는 서치콘솔 연동으로 보완 |
| 회원가입 폼 `search_keyword` | 사용자가 직접 적은 키워드(현재 유일한 데이터) | 자기보고, 입력률 10% |
| 인스타그램 | 인스타에는 "검색어" 개념이 약함 → **어떤 게시물/스토리/프로필 링크**를 눌렀는지 UTM으로 식별 | |

### Q2. 구매로 이어지는 **키워드·유입경로**는?
- GA4 **소스/매체(source/medium)** + **UTM** 캠페인 차원으로 세션을 분류하고, `purchase` 이벤트를 전환으로 표시 → "유입경로별 구매수·매출" 리포트
- 유료 키워드는 광고 플랫폼 전환추적(GA4 연동 또는 네이버 전환 스크립트) → 키워드별 ROAS
- **가장 확실한 방법(2단계)**: 첫 방문 시 `utm_*`/referrer/랜딩페이지를 쿠키에 담아 **회원가입·결제 시 DB에 저장** → 광고 차단기·쿠키 유실과 무관하게 **매출을 채널에 귀속**, 관리자 화면에서 바로 집계. 가입 당일 결제가 65%라 효과 큼
- 참고: GA4 기본 어트리뷰션은 데이터 기반/라스트 클릭(다이렉트 제외). 퍼스트 터치는 GA4의 "사용자 획득" 리포트 또는 자체 저장으로 확인
- **키워드 단위**로 어디까지 가능한지는 3-5에서 경로별로 정리

### Q3. 어떤 페이지에서 **얼마나 체류**하고, 어떤 경우 **결제**로 이어지나?
- GA4: 페이지별 **평균 참여 시간**, 조회수, 이탈률(참여율), **경로 탐색(path exploration)**, **유입경로 탐색(funnel exploration)**: 홈 → vod → vodDetail → orderConfirm → paymentComplete 퍼널 전환율
- **Microsoft Clarity**(무료): 히트맵·스크롤 깊이·세션 녹화 → "상세페이지 어디까지 읽고 떠나나", "결제 버튼 근처에서 뭘 망설이나"를 눈으로 확인. GA4와 연동 가능
- 서버 DB: pending→approved 79%(결제창 이후 구간), 상품별·쿠폰별 전환 — 이미 가능
- 영상 페이지(`lecturePlayer`)는 결제 이후라 마케팅 측정 범위 밖(수강 유지·재구매 분석엔 `member_lecture_progress` 활용 가능)

### Q4. 인스타그램 유입은 구체적으로?
- 인스타 **프로필 링크·스토리 링크·광고 링크 전부 UTM** 부착(`utm_source=instagram&utm_medium=social|paid_social&utm_campaign=…&utm_content=게시물식별`). 인스타 인앱 브라우저는 referrer를 자주 지우기 때문에 UTM 없으면 "direct"로 잡힘 — **UTM 없는 인스타 유입은 측정 불가에 가까움**
- **Meta 픽셀 + 전환 API**: 인스타/페북 광고의 전환(결제) 측정과 리타게팅 모집군 생성 — 광고 집행 시 필수. 광고 안 하면 GA4+UTM으로 충분
- 인스타 **인사이트**(앱 내): 도달·프로필 방문·링크 클릭 — 사이트 측 데이터와 교차 확인

### 3-5. "키워드 → 결제"를 어디까지 알 수 있나 (사용자와 정리한 결론)

**현재**: 가입폼 자기보고(가입경로 체크박스 + 검색키워드 자유입력, 키워드 입력률 10%)뿐. 실제 유입·페이지 흐름은 어디에도 기록되지 않음.

**도구 설치 후, 유입 경로별로 알 수 있는 범위**
| 유입 경로 | 어떤 키워드로 왔는지 | 결제와 연결(사람 단위) | 비고 |
|---|---|---|---|
| **검색광고**(네이버 검색광고·구글 Ads) | ✅ 클릭 단위로 키워드(입찰 키워드·실제 검색어) 확보 | ✅ 클릭 → 가입/결제까지 연결 가능 | 유일하게 "사람 단위 키워드→결제"가 되는 경로 |
| **일반(오가닉) 검색** | ⚠️ 검색엔진이 검색어를 사이트에 넘기지 않음. 서치콘솔·서치어드바이저에서 **검색어별 노출·클릭 합계**만 | ❌ 어떤 사람이 어떤 검색어로 왔는지는 못 이음 | 랜딩페이지 단위로 근사(아래 ②) |
| **인스타·카페·블로그·유튜브·카톡** | 키워드 개념 없음 → **UTM 링크**가 있어야 "어느 게시물/링크"인지 식별 | ✅ UTM이 있으면 세션→결제 연결, 없으면 direct로 뭉침 | 링크 교체 작업이 전제 |
| **직접 유입**(주소 직접 입력·북마크·UTM 없는 앱 링크) | ❌ | ❌ | 측정 불가 덩어리. UTM 보급률을 높일수록 줄어듦 |

**광고 없이 "키워드→결제"를 근사하는 방법 3가지**
1. **가입폼 검색키워드 필수화 또는 선택지화** — 자유입력(입력률 10%)을 "인터넷 검색" 선택 시 키워드 필수 입력 또는 핵심 키워드 선택지(편입논술 / 연고대 편입 / 한예종 논술 / 독편사 / 기타 직접입력)로 바꿈. 가입 당일 결제가 65%라 가입폼 데이터가 결제와 거의 1:1로 붙음. 개발량 가장 적음(`join.html:212-213`, `server.js:2309-2345` 저장 로직은 그대로).
2. **서치콘솔 "검색어→도착페이지" × GA4 "도착페이지별 결제율"로 추정** — 예: "한예종 논술" 검색 클릭이 대부분 특정 상세페이지로 들어오고 그 페이지의 결제율이 N%라면 키워드 기여를 추정. **키워드별 전용 랜딩페이지가 있을수록 정확**(현재는 모든 검색이 홈·vod 목록으로 들어와 섞임 → 상품별 상세페이지 SEO가 곧 측정 정밀도).
3. **네이버 애널리틱스의 검색어 리포트** — 네이버 검색 유입은 일부 검색어를 보여줄 수 있으나 브라우저 리퍼러 정책상 비율은 **설치 후 확인**. 구글 검색은 어떤 도구로도 사람 단위 검색어 불가.

**어떤 방법으로도 넘지 못하는 한계**
- **크로스디바이스**: 폰에서 탐색·검색하고 PC에서 결제하면 다른 사람으로 보임(로그인 후 GA4 `user_id`로 일부 봉합 가능, 비로그인 구간은 불가)
- **비로그인 방문**: 가입 전 방문은 익명 세션으로만 집계
- **과거 데이터 소급 불가**: 설치일 이후만

**검색광고 팁(회의용)**
- 브랜드 키워드("독편사", "독편사 편입")는 경쟁이 적어 클릭 단가가 낮은 편 — 타사가 브랜드명으로 광고를 거는지 방어 겸 확인. 단가 실측치는 **광고 계정 개설 후 키워드도구에서 확인**(여기서 추정하지 않음).
- 핵심 키워드 **소수(5~10개)·소액**으로 테스트 집행 → 키워드별 가입·결제율을 몇 주 확보한 뒤 확대/중단을 판단. 테스트 자체가 "어떤 키워드가 돈이 되는가"에 대한 가장 직접적인 데이터.

### 3-6. 비용 구분, 네이버 vs 구글 비교, 계정 주소

**비용**
- 분석 도구는 **전부 무료**: GA4, GTM, Google Search Console, 네이버 서치어드바이저, 네이버 애널리틱스, Microsoft Clarity, UTM(그냥 링크 규칙). **GA4 360(유료판)은 이 규모에서 전혀 불필요.**
- **유료는 검색광고를 집행할 때의 클릭당 광고비만**. 광고 계정 개설·전환 추적 설정·키워드도구 조회는 무료. Meta·카카오 광고도 동일(계정·픽셀 무료, 노출/클릭 과금).

**네이버 검색광고 vs 구글 Ads — 키워드를 DB에 저장하는 관점**
| 항목 | 네이버 검색광고 | 구글 Ads |
|---|---|---|
| 도착 URL에 붙는 것 | "추적 기능" 켜면 `n_media`, `n_query`(**실제 검색어**), `n_keyword`(입찰 키워드), `n_ad_group`, `n_campaign_type` 등 **평문 파라미터** | "자동 태그" 시 `gclid`(불투명 ID)만 |
| 키워드 확인 | URL 파라미터로 즉시 → **서버가 받아 바로 DB 저장 가능**(2단계 쿠키 로직에 `n_*`를 UTM처럼 함께 담으면 끝) | Ads ↔ GA4 연결로 리포트에서 확인. DB에 넣으려면 `gclid`를 저장해 두고 Ads 보고서/API와 **매칭하는 한 단계가 더** 필요 |
| 입찰 키워드 ≠ 실제 검색어 | `n_keyword`(입찰) vs `n_query`(실제) 둘 다 옴 | 입찰 키워드는 매칭 유형에 따라 확장됨 → 실제 검색어는 "검색어 보고서"에서 |
| 전환 추적 | 네이버 전환 스크립트(프리미엄 로그분석) 또는 GA4 UTM | Ads 전환 태그 또는 GA4 전환 가져오기 |
| 수험생층 적합도 | 편입 수험생 정보탐색은 네이버 비중이 높은 편(카페·블로그·지식인) | 보조. 유튜브 광고와 함께 묶여 있음 |

→ **네이버 우선, 구글 보조**를 제안. 실제 유입 비중(네이버 vs 구글)은 GA4·서치콘솔·서치어드바이저 **설치 후 확인**해서 예산 배분.

## 4. 필수 사전지식 용어집 (실무형)

| 용어 | 뜻 | 회의에서 쓰이는 맥락 |
|---|---|---|
| 사용자 / 세션 / 페이지뷰 | 사람 수(쿠키 기준) / 한 번의 방문(30분 비활동 시 종료) / 페이지 조회 | "월 방문 몇 명?" = 사용자 또는 세션 |
| 소스 / 매체 (source/medium) | 어디서(google, naver, instagram) / 어떤 방식으로(organic, cpc, social, referral, email) | "네이버 오가닉 vs 네이버 광고" 구분 |
| UTM 파라미터 | 링크 뒤에 붙이는 `utm_source/medium/campaign/content/term` — 우리가 직접 출처를 라벨링 | 인스타·카페·카톡 링크 관리 규칙 |
| 리퍼러(referrer) | 브라우저가 알려주는 "직전 페이지" — 앱·HTTPS→HTTP·인앱브라우저에서 자주 유실 | 유실분이 "direct/(none)"로 뭉침 |
| 랜딩 페이지 | 세션의 첫 페이지 | 어떤 상세페이지로 들어오는 광고가 잘 되나 |
| 전환(conversion) / 전환율 | 목표 행동(가입, 결제) / 전환 ÷ 세션(또는 사용자) | 결제 전환율 1~3%대가 일반적 e-커머스 범위(교육 고가상품은 더 낮을 수 있음) |
| 퍼널 | 홈→목록→상세→주문→결제완료 각 단계 이탈 | 어디서 새나 |
| 참여 시간 / 이탈률 | GA4는 "참여 세션"(10초+·2페이지+·전환) 기준, 비참여 비율=이탈률 | 체류시간 질문의 GA4 용어 |
| CAC | 고객 1명 획득 비용 = 마케팅비 ÷ 신규 결제자 | 채널별 비교 |
| ROAS | 광고비 대비 매출 = 매출 ÷ 광고비(×100%) | 키워드·캠페인 효율 |
| LTV | 고객 1명이 평생 내는 매출(재구매 포함) — 현재 재구매자 9/34 | CAC 상한 결정 |
| 어트리뷰션 | 전환을 어떤 접점에 귀속할지. **퍼스트 터치**(처음 알게 한 채널), **라스트 터치**(결제 직전 채널), 데이터 기반 | 인스타(인지)→네이버 검색(결제)일 때 공을 누구에게 |
| 리타게팅 / 리마케팅 | 방문했으나 미결제자에게 다시 광고 노출 — 픽셀 필요 | Meta·구글·카카오모먼트 |

## 5. 편입 학원 업계 맥락 (일반 지식 수준 — 수치는 원청 확인 필요)

- **시즌성**: 편입 전형은 통상 12월 말~1월(모집·논술/필기)에 집중되고, 합격 발표는 1~2월. 따라서 ① **상반기(2~3월)**: 새 학기 결심·기초반 모집, ② **7~10월**: 본격 대비·실전반 모집 성수기, ③ **11~12월**: 막판 특강·파이널, ④ 1~2월: 발표 후 재도전/차년도 선점. 자사 DB도 **7~10월·2월 가입 피크**가 수년간 반복되어 이 패턴과 일치. → 측정 도구는 **11월 전**에 깔려야 올 시즌 데이터를 얻음.
- **채널 특성**(국내 입시·교육 일반):
  - **네이버**가 정보탐색의 중심 — 검색광고(파워링크·브랜드검색), **블로그·카페**(편입 커뮤니티 활동이 매우 활발, "독편사 카페"가 이미 자체 채널), 지식인. 자기보고 데이터에서도 카페 13 + 검색 11로 온라인 유입의 대부분.
  - **유튜브**: 설명형·합격수기 콘텐츠로 신뢰 형성(원장 채널 존재). 유튜브→사이트 전환은 설명란 UTM 링크로만 추적 가능.
  - **인스타그램**: 20대 초중반 타깃 도달·브랜딩, 합격 인증·릴스. 전환 직접 기여보다 **인지 단계** 역할이 큰 경우가 많아 퍼스트 터치 관점이 필요.
  - **카카오채널**: 상담·리타게팅(알림톡/친구톡) 채널. 이미 운영 중(`pf.kakao.com/_axiEiG`).
  - 오프라인 재원생 전환이 60% → **학원 내부 안내(QR·문자)에도 UTM** 붙여 온라인 신규와 분리해야 "진짜 마케팅 유입"이 보임.
- **키워드 예시**(자사 DB의 자기보고 키워드 + 일반 조합): 편입논술, 연고대 편입, 연세대 편입(논술), 고려대 편입, 편입논술학원, 편입 논술 인강, 한예종 논술, 경찰대(소수), 독편사(브랜드). 경쟁 강도·검색량은 **네이버 검색광고 키워드도구/구글 키워드플래너**에서 확인해야 하며 여기서는 지어내지 않음.
- 채널별 운영·측정·비용의 상세는 6장.

## 6. 기타 마케팅 채널 가이드 (편입 학원 맥락, 일반 지식 수준)

> 각 채널의 "측정" 열은 1단계(GTM/GA4/UTM)가 깔린 뒤에 작동한다. 비용·효과 수치는 업계 평균을 적지 않았으며, 집행 후 자사 데이터로 채운다.

### 6-1. 인스타그램 (오가닉 + Meta 광고)
- **특징**: 20대 초중반 수험생에게 도달·브랜딩. 직접 결제보다 "이 학원 알게 됨"(퍼스트 터치) 역할이 큼. 인앱 브라우저가 리퍼러를 지우므로 UTM 없으면 측정 불가.
- **적합 콘텐츠**: 합격 인증·합격자 인터뷰 릴스, 논술 1분 팁, 설명회 안내, 강사 숏폼, 쿠폰 공지 스토리.
- **측정**: 프로필 링크 1개 제한 → **링크인바이오**(사이트 자체 페이지 `/links.html` 같은 걸 만들거나 외부 서비스)로 여러 UTM 링크 노출. 스토리 링크·게시물 언급 링크마다 `utm_content`로 구분. 광고 시 **Meta 픽셀 + 전환 API**(GTM으로 주입, 서버측은 approve 시점). 앱 내 **인사이트**(도달·프로필 방문·링크 클릭)와 GA4 유입을 교차 확인.
- **비용**: 오가닉 무료(제작 인건비). Meta 광고는 노출/클릭 과금, 일 예산 설정 가능. 리타게팅(상세페이지 방문·미결제자)이 가장 효율 좋은 편.
- **우선순위**: 오가닉 UTM 정비는 **즉시**. 광고는 픽셀 깔고 상세페이지 방문자가 쌓인 뒤 리타게팅부터.

### 6-2. 유튜브
- **특징**: 신뢰 형성·검증 채널. 원장 채널(`@hwangsungchan_1`)이 이미 있음. 검색(유튜브·구글) 노출로 롱테일 유입.
- **적합 콘텐츠**: 강의 맛보기(VOD 인트로를 공개 영상으로 재활용 — `is_public` 인트로 1편 체계와 연결), 합격수기, 설명회 녹화, 기출 해설, 학업계획서 특강 예고.
- **측정**: 설명란·고정댓글·카드 링크에 UTM(`utm_source=youtube&utm_medium=video&utm_content=영상ID`). 유튜브 스튜디오 애널리틱스(조회·시청시간·트래픽 소스). 구글 Ads 동영상 광고 시 Ads 전환 추적 또는 GA4 연결.
- **비용**: 오가닉 무료(편집 비용). 동영상 광고(인스트림·인피드)는 조회/노출 과금.
- **우선순위**: 기존 영상 설명란 UTM 교체 **즉시**(개발 불필요). 광고는 시즌 피크 직전 인지용으로 검토.

### 6-3. 네이버 블로그·카페
- **특징**: 편입 정보탐색의 중심. **독편사 카페가 이미 가입경로 2위(13+3명)** — 보유 자산. 블로그(`m.blog.naver.com/sociology-`)도 운영 중. 네이버 검색 결과(VIEW/인플루언서 탭)에 노출돼 **오가닉 검색 유입을 키우는 콘텐츠 SEO 채널**이기도 함.
- **적합 콘텐츠**: 합격수기·첨삭 사례, 기출 분석, 전형 일정 정리(검색 수요 큼), 체험단/후기(자사 재원생), 카페 공지·이벤트(쿠폰).
- **측정**: 카페 공지·메뉴·블로그 본문 링크에 UTM(`utm_source=naver_cafe|naver_blog&utm_medium=organic_post`). 카페는 글 수정이 쉬워 UTM 교체 비용 낮음. 네이버 애널리틱스로 네이버 생태계 유입 보완. **브랜드 검색("독편사") 증가**가 카페·블로그 활동의 간접 지표(서치어드바이저·서치콘솔로 추적).
- **비용**: 무료(운영 인력). 체험단·외부 블로거 활용 시 콘텐츠 비용 + 표시광고법상 "협찬" 표기 필요.
- **우선순위**: **최우선**. 이미 유입이 있는 채널이라 UTM만 붙이면 바로 매출 귀속 가능.

### 6-4. 카카오 (카카오톡 채널 · 알림톡/친구톡 · 카카오모먼트)
- **특징**: 상담·재방문 유도·리타게팅 채널. 채널(`pf.kakao.com/_axiEiG`) 이미 운영. 결제 완료·수강 안내 등 **거래 메시지(알림톡)**와 **광고 메시지(친구톡)**가 구분됨.
- **적합 콘텐츠**: 1:1 상담, 설명회·마감 알림, 쿠폰 발송(친구톡), 결제/수강 안내(알림톡 — 광고 아님).
- **측정**: 채널 소개·메시지 내 링크 UTM(`utm_source=kakao&utm_medium=message|channel`). 카카오모먼트 광고 시 **카카오 픽셀&SDK**(GTM 주입) + 전환 추적. 채널 관리자센터에서 친구 수·메시지 클릭.
- **비용**: 채널 개설 무료. 알림톡/친구톡은 건당 메시지 비용(발송 대행사 경유). 카카오모먼트는 노출/클릭 과금.
- **유의**: 친구톡은 광고성 → 채널 친구 추가가 곧 수신동의지만 야간 발송 제한·(광고) 표기 규정 적용(6-7).
- **우선순위**: 상세페이지·결제완료 페이지에 **채널 추가 버튼** 노출(코드 소량) → 미결제자 친구톡 리타게팅은 중간.

### 6-5. 네이버 광고 상품 간단 소개
| 상품 | 무엇 | 적합 용도 | 측정 |
|---|---|---|---|
| **파워링크(검색광고)** | 검색 결과 상단 텍스트 광고, 클릭 과금 | "편입논술", "한예종 논술" 등 의도 명확한 키워드 획득. 3-5의 **키워드→결제 사람 단위** 추적이 되는 유일 경로 | `n_query` 등 추적 파라미터 → DB 저장, 네이버 전환 스크립트 |
| **브랜드검색** | "독편사" 검색 시 상단 큰 브랜드 영역(이미지·링크 여러 개) | 브랜드 검색량이 일정 수준일 때 점유·방어. 기간 정액 과금 | 링크마다 UTM |
| **파워컨텐츠** | 검색 결과 VIEW 영역에 블로그형 콘텐츠 광고 | 정보성 키워드("편입 논술 준비법")에 블로그 글로 유입 | UTM + 네이버 애널리틱스 |
| **쇼핑검색·플레이스** | 상품/지도 | 해당 없음(학원 플레이스는 오프라인 안내용으로 등록·관리) | — |
| **성과형 디스플레이(GFA)** | 네이버 앱·밴드 등 배너, 타게팅 | 리타게팅·인지. 검색광고 다음 단계 | 네이버 전환 스크립트 |

→ 순서 제안: 파워링크 소액 테스트 → 브랜드 검색량 확인 후 브랜드검색 → 콘텐츠 축적 후 파워컨텐츠.

### 6-6. 오프라인 · 재원생 추천
- **현황**: 재원생 62/108명(57%, 복수선택 포함 시 60%)이 최대 유입. 결제자도 18명으로 최다. 그런데 **어떤 안내(강의실 QR·문자·구두)로 들어왔는지는 전혀 모름**.
- **추천 프로그램**: `members.referrer_code` 컬럼과 가입폼 입력란(`join.html:251-252`)이 **이미 존재**하나 사용 1명. 재원생/수강생에게 고유 추천 코드를 부여하고 **추천인·피추천인 양쪽에 쿠폰** 보상(쿠폰 체계 이미 있음) → 추천 경로가 DB에 코드로 남아 **광고 없이도 100% 귀속되는 채널**. 개발: 코드 발급·검증·보상 로직(2단계 묶음 가능).
- **오프라인 UTM**: 강의실 포스터·안내문 QR, 상담실 안내 카드, 교재 속지 등 매체별 `utm_source=offline&utm_medium=qr&utm_content=classroom_a` 식으로 구분. QR 생성은 무료.
- **쿠폰 코드 = 오프라인 어트리뷰션**: 채널별 다른 쿠폰 코드(설명회용·재원생용·카페용)를 발행하면 결제 시 `payments.coupon_id`로 채널이 남음(개발 0, 운영 규칙만).
- **우선순위**: **최우선**(가장 큰 유입원인데 측정 비용이 가장 낮음).

### 6-7. 이메일 · 문자 마케팅
- **현황**: 신규 108명 중 이메일·SMS 마케팅 **모두 동의 14명(13%)**, 모두 거부 82%. 자사 발송 채널은 매우 좁음 → 동의율을 올리는 UX(가입 시 혜택 명시)가 선행 과제.
- **적합 용도**: 미결제 장바구니 리마인드(결제창 열고 이탈 100건), 신규 강좌 출시, 시즌 특강, 쿠폰 만료 알림. 수강생 대상 거래 안내(결제 확인·수강 만료)는 광고가 아니므로 동의 무관.
- **측정**: 메시지 내 링크 UTM(`utm_source=sms|email&utm_medium=message&utm_campaign=…`). 발송 솔루션의 클릭률과 GA4 유입 대조.
- **법적 유의(정보통신망법 제50조)**: ① 광고성 정보는 **사전 수신동의자에게만**(`members.*_marketing_consent` 확인 로직 필수) ② 제목/본문 앞 **"(광고)"** 표기, 발신자 명칭·연락처·**수신거부 방법** 명시 ③ **오후 9시~익일 오전 8시** 광고 전송은 별도 동의 필요 ④ 수신동의 **2년마다 재확인** 의무 ⑤ 수신거부 처리 결과 통지. 거래 관련 안내(결제 완료·수강 안내)는 광고 아님.
- **비용**: 문자 건당 과금(발송 대행), 이메일 저렴/무료 플랜. 알림톡은 문자보다 저렴한 경우가 많음.
- **우선순위**: 중간. 동의자 수가 적어 매출 효과는 제한적이나, 결제 이탈 리마인드는 단가 대비 효율이 높은 편.

### 6-8. 리타게팅 개념과 필요한 픽셀
- **개념**: 사이트에 와서 상세페이지를 봤거나 결제창을 열었지만 결제하지 않은 사람에게, 다른 매체(인스타·구글·네이버·카카오)에서 다시 광고를 보여주는 것. 고가 교육상품처럼 **고민 기간이 긴 상품**에 효과적. 현재 데이터로는 결제창 열고 이탈 100건(expired)이 1차 모집군 후보.
- **필요한 것**: 매체별 픽셀(Meta 픽셀, Google Ads 리마케팅 태그/GA4 오디언스, 네이버 전환 스크립트, 카카오 픽셀) — **전부 GTM에서 추가**, 코드 수정 없음. 모집군 조건은 "vodDetail 조회", "orderConfirm 도달 후 paymentComplete 미도달" 등 GA4/픽셀 이벤트로 정의.
- **제약**: iOS 추적 제한·광고차단으로 브라우저 픽셀만으로는 누락 → **전환 API(서버측)** 병행이 정석(3단계). 리타게팅 광고도 개인정보처리방침에 행태정보 수집·이용 기재 필요(8장).

## 부록 A. UTM 명명 규칙 초안
- `utm_source`: `instagram` / `youtube` / `naver_blog` / `naver_cafe` / `naver` / `google` / `kakao` / `sms` / `email` / `offline`
- `utm_medium`: `social` / `paid_social` / `cpc` / `video` / `organic_post` / `referral` / `qr` / `message` / `channel`
- `utm_campaign`: `2026w_final`(시즌_상품) 형식, 소문자·언더스코어
- `utm_content`: 게시물·소재 식별(`reel_0915`, `story_coupon`, `classroom_a`, `yt_<영상ID>`)
- 예: `https://dockteacher.co.kr/vodDetail.html?id=26&utm_source=instagram&utm_medium=social&utm_campaign=2026w_premium&utm_content=profile_link`
- 네이버 검색광고는 UTM 대신(또는 함께) 플랫폼이 붙이는 `n_media/n_query/n_keyword/n_ad_group`를 그대로 저장. 구글 Ads는 `gclid` 저장 + UTM 수동 병기 권장(`utm_source=google&utm_medium=cpc`).

## 부록 B. 집계에 사용한 테이블·컬럼
`members(member_group, joined_at, signup_channel, search_keyword, referrer_code, *_marketing_consent)`, `payments(status, amount, approved_at, vod_course_id, coupon_id, member_id)`, `coupons(status)`, `member_vod_enrollments(source)`, `vod_courses(title)`. 개인정보 컬럼은 조회하지 않음. 집계 스크립트는 세션 스크래치 디렉터리에만 두고 저장소에 포함하지 않음.
